# 授業管理アプリ

## 誰の、どんな困りごとか
対象者： 個人で教室を運営する講師
課題： 授業料の徴収や生徒の出席確認をノートに手作業で行っており、管理に時間と手間がかかっている。ま
た、支払い状況を個別に確認する必要がある。

## コア機能1つ
生徒情報の管理： 生徒ごとの氏名や受講情報を登録する。
授業料・支払い管理： 生徒ごとの授業料の支払い状況を記録する。
出席管理： 生徒の出席状況を記録し、履歴を確認できる。
これらの情報を一つのシステムで管理することで、手作業による手間を減らし業務を効率化する。

## 誰が・いくら・なぜ払うか
支払う人：個人で教室を運営する講師
価格：　月額500～1000円程度
支払う理由：　手作業による情報の記録や管理を一元管理することで作業時間を削減できる上に、支払い状況の確認漏れを防ぎやすくなる。また、生徒の出席状況を容易に把握することができる。

## 17:15 に見せる操作
出席ボタンを押すと出席状況一覧に出席と表示される。
